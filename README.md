# DIS Core · Design Intent System

**Версия:** v2 Alpha · **Назначение:** исследование и разработка дизайн-концепций цифровых продуктов с контролем этапов, сохранением решений и проверкой результатов.

> **Alpha:** методология, промпты и проверяемые модули доступны для тестирования. Независимый сервис подтверждения личности оператора и обязательная блокировка всех прямых действий ChatGPT/Codex/Figma **ещё не подключены**. Процедурное согласие с этапом не равно защищённому `APPROVED`.

## Начать работу

1. Прочитайте [инструкцию для новичка](docs/dis-operator-guide-v2-alpha.md).
2. Создайте **отдельный приватный репозиторий** для своего учебного или клиентского проекта (не в этом репозитории).
3. Откройте новый чат ChatGPT, приложите материалы задачи и вставьте **целиком** [стартовый промпт v2](prompts/dis-project-bootstrap-v2.md), указав ссылку на репозиторий проекта.
4. Выберите с DIS стратегию и три независимые области — **Research / Design / Delivery**. Не разрешайте генерацию HERO до прохождения применимых этапов.
5. Для завершения текущего этапа напишите **«Переходим к следующему этапу»**. DIS должна показать результаты, проверки и выбор «Углубить / Доработать / Утвердить этап».

**Входные документы:** [Master Process](methodology/dis-master-process-v1.md) · [Alpha Start](distribution/ALPHA-START.md) · [Alpha Approvals](distribution/alpha-approval-procedure.md) · [Обезличенная база знаний](knowledge/README.md).

## Необязательное наблюдение за альфа-пилотом

При отдельном согласии новичка DIS может вести **минимальный журнал маршрута, ошибок и попыток исправления** в его приватном проектном GitHub. Записи переписки и экрана нет; наблюдение не включается автоматически. [Pilot Monitor v0.1](docs/pilot-monitor-v0.1.md).

## Что включено

Профессиональная методология исследований, проектирования и арт-дирекшна, поэтапные промпты, инструкции для Codex Skills, Python-модули проверок, библиотека обобщённых ошибок и сценарий альфа-пилота. Контроль целостности этого репозитория запускается через GitHub Actions.

## Границы и права

В этом репозитории **нет оригинальных клиентских брифов, макетов и истории частных проектов**. Пакет был автоматически очищен и проверен на внутренние ссылки, но **автоматическая обработка не заменяет окончательную редакционную и юридическую проверку**.

NMT / Next Move Theory — отдельный внешний проект с собственной лицензией (CC BY-NC-SA 4.0); сторонние skills и канон здесь не распространяются. Условия лицензирования самого DIS Core следует определить отдельно — наличие публичного GitHub-репозитория само по себе не предоставляет лицензию на повторное использование.

При любом сомнении в правах на материал не публикуйте его. Для работы с настоящим заказчиком используйте приватный проектный репозиторий.
