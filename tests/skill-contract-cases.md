# DIS — Skill Contract Test Cases · v1.0

**Режим:** спецификация ожидаемого поведения, **не утверждение о прошедших автоматических тестах**. Каждый случай должен быть пройден вручную или программно с проверяемым логом. Статус suite на 26.10.2026: `specified_not_executed`.

## Минимальный критерий «скилл проверен»

Для `verified` нужно зафиксировать дату, исполняющий инструмент, тестовую фикстуру, фактический результат и расхождения каждого применимого кейса. Наличие таблицы ещё **не тест**. При fail исправить контракт/код, прогнать regression и сохранить checkpoint.

Сценарии обучения Studio Signature **не** становятся фактическими художественными предпочтениями пользователя до его реального выбора в конкретном проекте.
