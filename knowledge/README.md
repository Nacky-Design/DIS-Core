# DIS Knowledge Base — обезличенная операционная память
**Статус:** Alpha · generic patterns derived from internal pilot retrospectives and audits. **Не клиентские кейсы.**

Это публичный слой знаний DIS, а не хранилище клиентских данных. Исходные ТЗ, переписка, артефакты, логотипы, скриншоты, секреты, точные пути клиентских репозиториев и неподтверждённые обстоятельства остаются в закрытых проектах. До публикации каждого знания необходим редакционный обзор на возможность восстановления личности/клиента по сочетанию деталей.

[Каталог повторяемых классов ошибок](lessons/dis-incident-patterns-v1.md) · [Контракт записи знаний](learning-contract-v1.md).

## Три уровня доказательности
- **OBSERVED_IN_INTERNAL_REVIEW** — проблема зафиксирована в доступном внутреннем аудите или ретроспективе; причины могут оставаться гипотезами.
- **STRUCTURALLY_TESTED** — существует негативный автоматический тест на машиночитаемое условие; не доказывает художественное качество и причинную эффективность.
- **EXPERIMENTAL** — подход требует реального сравнения на новых проектах.

## Как применять
При старте этапа использовать каталог как *анти-регрессионные подсказки* только если сценарий применим. Нельзя превращать пример пилота в универсальный токен, требовать одинаковый визуальный стиль или считать экспериментальное правило обязательным для всех сайтов. Клиентские решения имеют собственные области и права.
