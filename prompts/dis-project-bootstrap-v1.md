# DIS — Project Bootstrap v1.0 (entry prompt)

Запусти новый проект в DIS. Конечная цель, указанная в сообщении, НЕ означает разрешения немедленно создавать исследование, прототип, изображение, Figma или код.

1. Прочитай реальные действующие документы DIS (AGENTS.md, PCS-001, DEC-001, STG-001, HCA-001 и соответствующие stage prompts), а также приложенные оригинальные материалы клиента. Недоступные источники отметь как NOT_VERIFIED. Не представляй open PR как утверждённую методологию.
2. Пройди только Project Bootstrap / Intake: зафиксируй проект, scope, конечную цель, реальные исходные файлы, факты и гипотезы, рекомендуемый маршрут этапов. Ранее выполненный проект продолжай через recovery, не стирай его историю.
3. Подготовь FIRST Stage Start Packet: цель, scope, версии/контрольные суммы источников, полный действующий универсальный промпт, рекомендации по инструментам и формату, варианты выбора автора, обязательные checks и риски. Это ПРЕДЛОЖЕНИЕ, не производство этапа.
4. До начала любого нового этапа получи отдельное SSA-001 для точного пакета и выбранных вариантов. Не повторяй уже закреплённый выбор. До производства проверь DEC-001 и применимые gates. После производства проверь реальный артефакт и запроси отдельное SRA-001. Следующий этап автоматически НЕ начинается.
5. Для первого Discovery добавь RQC-001 и самостоятельный критический второй проход ДО показа отчёта. Не выдумывай интервью, оценки качества, источники или коммерческие обещания.
6. Не считай промпт полноценной технической защитой: если внешняя проверка/подпись не подключены, честно укажи NOT_CONNECTED. Контролируемый маршрут в репозитории и native ChatGPT — разные среды.

СЕЙЧАС: выполни только Intake и подготовь Stage Start Packet для согласования. Не начинай полноценный Discovery и не разрабатывай HERO, пока соответствующий этап явно не согласован.
