# DIS — Information Architecture · Stage Contract v1
**Stage:** `information_architecture` · **Status:** CANDIDATE; for chosen multi-page/full-product research scope.

**Inputs:** selected Research/Design Scope, approved research and strategy, catalog/service taxonomy, Jobs, core user journeys, existing product architecture, content and technical constraints.

**Purpose:** define the information architecture of the **researched product**, even when Design Scope contains only HERO or homepage.

**Work:** (1) inventory content and entities, (2) map audience tasks and destinations, (3) propose sitemap/template taxonomy, (4) trace navigation and critical flows, (5) document transaction/empty/error states where relevant, (6) identify mobile navigation and SEO structure implications, (7) compare alternative structures and ask operator to choose.

**Output:** one versioned IA artifact: sitemap, page-type map, user-route matrix, navigation principles, dependency and unknowns ledger. Deliverable does not claim full wireframes or every interior page.

**Stage Acceptance:** every selected critical Job has a discoverable route; required content has an owner/location; no mutually inconsistent navigation; all locked source decisions preserved; exclusions and validation debt explicit. No invented features or assumptions marked VERIFIED.

**Exit:** Stage Exit Check → decision summary → deepen/revise/approve → verified GitHub SRA. Separate SSA for next stage.
